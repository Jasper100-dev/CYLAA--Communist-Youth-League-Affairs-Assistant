团务助手 - 隐私政策

生效日期：2026 年 11 月 19 日（2026 年 11 月 23 日更新）　|　适用版本：GitHub 发布版 v0.4.0 及以后

本政策只适用于 GitHub 发布版。Microsoft Edge 加载项商店版使用单独的政策（见 商店版隐私政策），两版的网络行为不同。本工具为第三方辅助工具，与智慧团建官方平台不存在授权或隶属关系。请在使用前完整阅读。

1. 我们收集和处理的数据

本扩展仅在智慧团建平台（https://zhtj.youth.cn）页面内运行，处理的数据来自您正在查看的页面、平台自身同源接口返回的数据、您主动导入的文件，以及您在面板中的操作。具体包括：

数据类型具体字段来源用途
团员基本信息姓名、性别、民族、手机号码、团内职务、团籍是否在本组织、入团年月、序号平台页面表格；导出名单时读取平台自身的导出文件（同源）名单核对、变更比对、CSV 导出
密码重置验证码姓名、验证码、有效期、记录时间平台弹窗文本本地记录与 TXT 导出，供您自行核对
评议与录入数据评议等级、表单字段名称与填写值您在面板中的设置批量设置与录入辅助
导入文件CSV / XLSX 文件内容您主动选择的文件录入前格式预检

本扩展不读取或保存您的平台账号密码。录入预检会在本机内存中读取您主动导入文件里的身份证号，仅用于格式与校验位检查，不写入存储、不上传。

2. 数据存储与保留

位置内容保留期限
浏览器内存当前名单、验证码记录、任务状态页面关闭即释放
chrome.storage.local名单变更快照（姓名 | 手机号）、上次更新时间、面板设置持久保存；名单变更快照与面板设置保留到卸载扩展，当前名单、验证码与评议缓存可在扩展内清除
sessionStorage评议缓存、字段模板、录入任务、系统字典浏览器会话结束时清除
本地导出文件团员名单 CSV、重置码 TXT保存在您指定的下载目录，由您自行管理

除上述位置外，本扩展不将团务数据写入其他存储，也不上传至扩展作者或第三方服务器。

3. 网络通信

  • 智慧团建平台（同源请求）：读取页面表格；调用 /v1/center/importenter 获取字典数据（民族、学历、政治面貌等）；导出名单时读取平台自身的导出文件（/v1/center/exportmembers/…）以补齐性别、团籍是否在本组织、入团年月。以上都使用您当前登录会话。
  • 版本检查（外部只读请求）：依次向 jasper100-dev.github.io（GitHub Pages）、cdn.jsdelivr.net、raw.githubusercontent.com 请求公开的 version.json，用于提示新版本。这类请求不携带任何团员个人信息，但服务器可能记录您的 IP 地址和访问时间。
  • 除以上情形，本扩展不发起其他外部网络请求。

4. 敏感信息处理

手机号码、姓名及密码重置验证码属于敏感个人信息。本扩展仅在您的设备本地处理这些数据；验证码只用于您主动触发的记录与导出，不发送给任何外部服务。导出文件包含敏感信息，请妥善保管，不要在公共设备或公开渠道传播。使用共享设备后，请及时清理下载目录中的导出文件。

5. 自动操作说明

名单抓取与数据预检由您在面板中主动触发；验证码记录会在您打开密码重置弹窗后自动进行。批量评议与批量录入功能在您启动任务并设置参数后，会先弹出确认窗口；只有您点击确认后，工具才会自动填写表单并点击页面的提交按钮。评议批量设置中，选择等次后由平台页面即时保存，效果等同提交。请在确认前核对目标人员与数据内容，并确认您对相关数据拥有合法的操作权限。本工具不改变平台的正式审批流程。

6. 您的权利与控制

  • 可随时停止正在运行的任务，或关闭/卸载本扩展。
  • 卸载扩展会一并清除 chrome.storage.local 与 sessionStorage 中的数据。
  • 本地导出文件需您自行删除；本扩展无法远程删除您设备上的文件。
  • 如发现数据处理与政策不符，请通过下方渠道反馈。

7. 第三方与责任限制

版本检查涉及 GitHub Pages、jsDelivr、GitHub 等第三方服务，其数据处理遵循各自的隐私政策。本工具依赖智慧团建平台页面结构，平台改版可能导致功能异常；涉及重要团务信息的操作，请以官方平台实际结果为准。使用者应遵守个人信息保护相关法律法规、平台使用规则及所在单位的数据管理要求。
